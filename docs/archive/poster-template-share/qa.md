## MCP 시뮬 검수 (앱측 — 미완, 사유 명시)

- 연결된 iOS 시뮬은 사용자 활성 세션이 **개인공고(커뮤니티) 상세**에 있었음. 포스터는 **공공 유기동물 공고(adopt/[id]) 전용**이라 해당 화면엔 진입점이 없는 게 정상.
- 유기동물 공고 화면 이동이 막힘: 딥링크(`keeper://`)가 dev 클라이언트에서 미등록(error 115), 시뮬이 **이미지 로딩 불능 상태**(모든 이미지 회색 플레이스홀더). 사용자 활성 세션을 헤집지 않기 위해 중단.
- **대체 근거**: 렌더 결과물은 라이브 백엔드 e2e로 완전 검증(위). 앱 진입점·시트·저장 훅은 코드 정합성 + 단위테스트로 검증.
- **후속**: 시뮬 이미지 로딩 정상화 후 adopt/[id]에서 버튼→시트→저장 흐름 시각 확인 권장(회귀 아님, 신규 UX 최종 확인).
