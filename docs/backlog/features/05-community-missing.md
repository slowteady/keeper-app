# 커뮤니티 "실종분실" 탭 — 실종신고 공고 게시판

> 상태: 발산 완료. 다음 단계 /prd. (인프라 이동과 병행)

## 배경

보호자가 잃어버린 동물을 찾기 위해 올리는 실종신고 공고 게시판. 커뮤니티 3탭(개인입양/실종분실/궁금해요) 중 가운데. 현재 탭 껍데기만 존재(빈 list + globalToast 플레이스홀더), 백엔드 엔티티·문서 없음.

## 확정된 결정

- **[Q1 확정] 분실 공고만** — 보호자가 "잃어버렸어요" 공고 작성. 목격/제보는 **그 공고의 댓글**로. 양방향 글(목격 별도 글)·매칭은 컷(초기 규모엔 과함, YAGNI).
- **[Q2 확정] 위치 = 지도 핀 + 좌표 저장** (완성도 높은 안) — 입력은 개인입양 `LocationBottomSheet`(카카오 주소검색→좌표) 재활용, 표시는 보호소 네이버맵 컴포넌트(`entities/shelter/ui/shelter-map.tsx`) 재활용. 좌표 컬럼 추가 + 상세화면 핀 표시. 반경 슬라이더는 나중.
  - spec 확인 필요: 카카오 Geocode 좌표(WGS84)가 네이버맵에 그대로 꽂히는지.
- **[Q3 확정] 해결 상태 = 배지 + 흐림 + 잔류** — "찾았어요" 토글 → "찾았어요" 배지 + 흐림 처리 + 미해결글 아래로 이동(목록 잔류). 미해결 필터로 숨김. 사유: 완전제거는 온기 손실(가족 매칭 정체성), 잔류+필터가 노이즈 제거 + 성공 사례 둘 다 잡음. (A 완전제거 / C 별도탭 컷)
- **[Q4 확정] 실종 일시 = 날짜 + 시간** — datetime 입력. 날짜 필수 + 시간 선택(보호자가 시각 모를 수 있음). 미래 날짜 차단. (spec: date/time picker 컴포넌트 유무 확인)
- **[Q5 확정] 정렬·필터 = 최신순 + (동물 종류 + 미해결)** — 정렬 최신순 단일. 필터는 동물 종류 ButtonGroup(QnA 패턴 재활용) + "찾는 중만" 토글. 지역 필터는 좌표만 저장해두고 글 쌓인 뒤(YAGNI).
- **[Q6 확정] 알림 = MVP 제외** — 반경 푸시는 초기 사용자 적어 가치 낮음 + 푸시 인프라 부담. **알림은 별도 기능으로 후속 독립 구현** 예정 (실종 전용 아님).

## 후속 / 별도 트랙

- **AI 포스터 폼채움** — `ai-poster-prefill.md` 참조. 실종 폼 확정 직후 Phase 1.5 후보.
- **알림(푸시)** — 실종 한정 아닌 앱 전반 알림 기능으로 별도 구현 예정.
- **지역/반경 필터** — 좌표 저장은 MVP, 필터·반경은 글 쌓인 뒤.

## 레퍼런스 BP 딥다이브 (해외 6개 서비스)

Petco Love Lost, PawBoost, PetFBI, Lost My Doggie, Nextdoor 조사. keeper 적용 기준:

| 항목      | 이식 (초기)                                             | 컷 / 나중                          |
| --------- | ------------------------------------------------------- | ---------------------------------- |
| 공고 필드 | 사진·위치·연락처 필수 + 종/품종/색상/실종일시/특징 선택 | 마이크로칩 DB연동, 보상금은 선택만 |
| 제보      | 댓글 (Nextdoor 모델)                                    | 전용 sighting 폼                   |
| 위치      | 지도 핀 + 좌표 (전문 서비스 공통 핵심)                  | 반경 슬라이더, 동선 추적           |
| 해결 상태 | "찾았어요" → 목록 정리                                  | 외부 DB 자동종료                   |
| 정렬·필터 | 종 + 지역 + 미해결                                      | 색상/품종 세분화                   |
| 알림      | 반경 푸시(FCM) — 검토                                   | SNS 자동공유, 전화/우편            |
| AI 매칭   | ❌ 과함 (PetFBI·PawBoost는 AI 없이 운영)                | 얼굴인식, Vision API               |
| 수익      | 무료/기부 (비영리 부합)                                 | 유료 구독·광고                     |

핵심 통찰: AI 얼굴인식은 1인운영 한계 초과로 컷. 지도 핀/좌표는 실종의 가장 차별적 UX.

## 백엔드 영향 (개요)

- PostType enum 에 `MISSING` 추가
- 신규 entity (post_missing): 개인입양 컬럼 재활용(animalType/specificType/age/weight/gender/images/특징) + 신규(실종 일시, 좌표 lat/lng, 해결 상태)
- 마이그레이션 다음 번호: 028 (keeper-api 측 재확인)
