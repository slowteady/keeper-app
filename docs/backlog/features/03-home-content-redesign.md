# 홈 화면 콘텐츠 재구성

- **상태**: 부분 구현 (배너·입양공고·근처 보호소 반영 / 공지·커뮤니티 프리뷰·입양후기 미구현)
- **일자**: 2026-06-02 (발산) · 2026-06-14 (입양공고 섹션 BP 재정비)

## 배경 / 문제

현재 홈 = 배너 + 입양공고 + 보호소(빈약) + 푸터. **입양공고 외 콘텐츠가 부족해 홈이 비어 보임.** 게다가 보호소 섹션(거리카운트·지도·가로카드)이 보호소 탭과 거의 중복(보호소 탭은 supercluster로 재설계 완료).

## 재구성 방향 (확정)

입양공고(동물 발견)를 메인으로 두고, **참여·운영·출처 콘텐츠로 보강**. 두 섹션의 축을 분리한다(입양공고 = "어떤 동물", 보호소 = "어디서/출처").

### 홈 스크롤 구성

```
0. 공지 띠배너 (중요 공지 1건, 0건이면 숨김 — 프로모 배너와 분리, 03-notice 참조)   ❌ 미구현 (03-notice 선행)
1. 배너 (프로모/이벤트 전용)                                                          ✅ 구현
2. 입양공고 (메인)                                                                    ✅ 구현 · 2026-06-14 BP 재정비
3. 커뮤니티 프리뷰 (개인입양·궁금해요 최신 1~2건 + "커뮤니티 가기")                    ❌ 미구현 ← 남은 최대 덩어리
4. 근처 보호소 (카드 2~3개 + 더보기, 경량화)                                          ⚠️ 구현(지도 제거) / 거리카운트 확정 필요
5. [입양후기 슬라이더 — 후기 게시판 기획 후 여기 추가]  ← adoption-review-board 참조   ⏸ 보류 (게시판 기획 선행)
```

## 보호소 섹션(홈) 축소 유지 사유

- 동물 큐레이션이 아니라 **위치/출처 축** → 입양공고(동물)와 겹치지 않음
- 공고(동물) → 보호소(출처) 흐름이 자연 (Petfinder/포인핸드식 "근처 보호소 X개")
- 보호소 탭(전체 지도 탐색, viewport)과 **역할 분리**: 홈 = 근처 요약(수동 발견), 탭 = 능동 탐색
- 거리카운트·지도 제거로 탭과의 중복 최소화

## 컷한 옵션 (사유)

- **입양후기 슬라이더 즉시 추가** — 표시만 가능하고 작성 흐름·게시판 미기획이라 데이터 없음. 게시판 기획 선행(adoption-review-board).
- **보호소 섹션 완전 제거** — 콘텐츠가 더 줄고 공고→출처 맥락 상실. 축소가 균형점.
- **긴급성 카드(마감임박 동물 많은 보호소)** — 입양공고의 마감임박과 메시지 중복, 입양공고 의미 희석. 컷.
- **사회적 증명 통계("이번 주 N마리 입양")** — 결국 동물 축이라 입양공고와 약하게 겹침 + 집계 API 필요. 후순위.

## 레퍼런스 BP

- **입양 성공 후기 = 전환 270%↑** ([genesysgrowth](https://genesysgrowth.com/blog/social-proof-conversion-stats-for-marketing-leaders)). Best Friends·ASPCA "Happy Tails"를 공고 다음 단독 섹션 → 입양후기 게시판의 가치 근거(별도 기획).
- **Petfinder/포인핸드** — 홈에 "근처 보호소 X개" 요약 → 보호소 축소·출처 맥락.
- **당근/Nextdoor** — 커뮤니티 최신 글 홈 노출(참여 유도) → 커뮤니티 프리뷰.
