## 0. 한 줄 요약

개인 **무상** 입양·임보 게시는 합법. 출시 전 법규 3가지(**금액란 금지·연락처 게이팅·신고/고지**)만 필수. 폼은 "입양 의사결정 도구" 수준으로 올리되 — 추가하는 성격·행동은 **자유서술이 아니라 enum/척도 태그**(Petfinder·KARA·핌피 표준 정합), **필수는 최소·나머지는 선택+단계 분리**. 부담은 필드 개수가 아니라 민감정보에서 오므로 비민감 태그는 많이 넣어도 됨. 매칭·채팅·위저드는 출시 후(P1).

## 1. 출시 전 필수 (P0) — 법규

### P0-1. 금액(책임비·입양비·임보비) 입력란 금지 `강행`

- 유상성 개입 시 무허가 동물판매업(2년↓/2천만원↓) + 통신판매중개자 의무 트리거. 포인핸드도 2022.4.1 책임비 기재 전면 금지.
- **현재 폼엔 금액 필드 없음 → 유지.** 임보 비용도 금액 입력이 아니라 **안내 텍스트**로만.

### P0-2. 연락처 — 본문 노출 금지, 문의 시 게이팅 노출 `권고(강행 아님), 출시 전 반영`

- PIPC 권고: 게시글 본문에 전화/이메일/계좌 직접 노출 지양.
- **출시 1차**: 연락처 3종(전화·이메일·SNS) 필드 유지, 본문 노출 X → 상세엔 `[문의하기]` 버튼만 → 로그인 유저가 누르면 면책·안전 고지 후 공개.
- 어떤 채널을 등록할지는 **게시자 자율**. keeper는 특정 채널 권장·유도 안 함.
- 앱 내 채팅은 P1(프로토타입 보유). 채팅 도입 후에도 contact 3종은 공존 가능.

### P0-3. 신고·삭제·임시조치 `강행`

- 정보통신망법 §44조의2: 권리침해 신고 시 지체 없이 삭제·임시조치(최장 30일)·양 당사자 통지.
- 상세에 신고 버튼 + 운영자 삭제/임시조치 흐름. (폼 아닌 게시판 기능)

### P0-4. 면책·고지 `면책 핵심`

- **이용약관**: keeper는 게시 공간일 뿐 거래 당사자·중개자가 아님, 분쟁 책임은 당사자.
- **개인입양 화면(1줄)**: "개인 간 입양·임시보호 공간입니다. keeper는 거래 당사자가 아니며, 입양 진행·분쟁 책임은 게시자·신청자에게 있습니다."
- **문의·안전 배너**: "만나기 전 송금하지 마세요. 동물을 직접(또는 영상으로) 확인하고 공공장소에서 만나세요. 금전 거래 분쟁에 keeper는 책임지지 않습니다."

### P0-5. 민감정보 미수집 `강행`

- 주민번호 등 고유식별정보 수집 금지(개인정보보호법). 현재 없음 → 유지. 게시·개인정보 처리 동의 절차 확보.

### P0-6. 구조 목적 악용 차단(최소) `권고`

- 포인핸드는 구조 필요성 "구조 스토리" 요구로 냥줍·사육포기와 구분. **최소**: 신고 사유에 "판매성/사육포기 의심" 추가 + 운영 검토.

## 2. 폼 설계 (조사 반영)

### 2-1. 형식 원칙 (조사 핵심)

- **성격·행동·건강·외형은 자유서술 금지 → enum / boolean / 척도(칩·토글)**. 근거: Petfinder API `environment{children,dogs,cats}` 3-boolean, `attributes` 건강 5-boolean, `age/gender/size/coat` enum 4축. 국내 KARA 활발함 4단계 척도, 핌피 배변·산책·짖음·분리불안·털빠짐·대인·대견 단계평가.
- **부담은 필드 '개수'가 아니라 '민감 정보'(전화·주소·나이 강요)에서 옴.** 비민감 구조화 태그는 다수 추가해도 부담↑ 작음.
- **필수는 최소, 나머지는 선택 + 접기/단계 분리.**
- ⚠️ 자유텍스트(현재 `likes`/`dislikes`/`specialMark`)에 성격을 흩지 말 것 — 구조화 태그로 대체, 자유 소개는 `소개글` 하나로.

### 2-2. 필드 (필수/선택 + 형식)

```
[필수 — 5]  ※ 이것만 채우면 게시 가능
 · 사진 1~10장 ( + 짧은 영상 1개, 권장 )
 · 보호유형  enum [임시보호][입양][둘다]
 · 종        enum [강아지][고양이][기타]
 · 제목
 · 소개글    (자유 텍스트 — 사연 포함 자유 서술)

[선택 · 외형]  enum (Petfinder 4축)
 · 나이 / 성별 / 크기(또는 체중) / 품종(강아지) / 색·털
 · 개인입양은 추정이 많아 전부 선택. 고양이는 품종 숨김(믹스묘)

[선택 · 건강]  boolean
 · 중성화 / 접종 (권장) / 배변훈련 / 특수요구·질병

[선택 · 성격·행동]  ★ 칩·척도 (자유서술 X) — 입양 의사결정 핵심
 · good with:  아이 / 다른 개 / 다른 고양이   (각 [가능][모름][어려움])
 · 활동성:  [얌전][보통][활발][매우활발]   (KARA식 4단계)
 · (옵션) 짖음 · 분리불안 · 사람 친화
 · 고양이도 동일 태그 사용 (묘종 대신 — 성격이 매칭 축)

[선택 · 구조 사연]  텍스트 (소개글과 별도로 강조하고 싶을 때)

[임보일 때만 · 임보 조건]
 · 기간  enum [단기][장기][협의]
 · 비용 안내  텍스트 (금액 입력 X)

[연락처]  전화/이메일/SNS — 문의 시 게이팅 노출(P0-2)
[동의]    게시·개인정보 처리 동의 + 면책 고지
```

### 2-3. 단계(섹션) 구성

- **멀티스텝 또는 섹션 접기**, 한 화면 5~7개 노출 (한 번에 다 보이지 않게).
- 권장 스텝:
  1. 사진·영상 + 기본(보호유형·종·제목·소개글) ← **필수 모임**
  2. 동물 정보(외형·건강)
  3. 성격·행동 태그 (+ 구조 사연)
  4. (임보 조건 — 임보일 때만)
  5. 연락처 + 동의
- 1단계만 채우면 게시 가능. 2~4단계는 "건너뛰기" 허용 → 부지런하면 풍부, 급하면 최소.

## 3. UI 설계

### 3-1. 글쓰기 (멀티스텝)

```
┌─────────────────────────────┐
│ ◀  1/5  사진·기본   ▓▓░░░    │
│                             │
│  [ + 사진 ]  [ + 영상 ]      │
│  보호유형  [임보][입양][둘다] │
│  종       [강아지][고양이]    │
│  제목     ________________   │
│  소개글   ________________   │
│           ________________   │
│                             │
│  [ 다음 ]   (이대로 게시 가능)│
└─────────────────────────────┘
   2/5 동물정보 · 3/5 성격 · 4/5 임보 · 5/5 연락
   → 2~4는 [건너뛰기] 허용
```

### 3-2. 목록 카드 (연락처 노출 X)

```
┌─────────────────────────────┐
│ ┌────┐  토리                │
│ │ 📷 │  [임보] 🐶 암컷·3살   │
│ └────┘  8kg · 경기 안성      │
│         #아이OK #개OK #차분   │  ← 성격 태그 1~3개
│         ♡12  💬3             │
└─────────────────────────────┘
```

### 3-3. 상세 화면

```
사진+영상 캐러셀
─ 이름 · [보호유형 뱃지] · 종·성별·나이·크기·지역
─ 성격·행동 (칩)   #아이OK #개OK #고양이모름 #활발
─ 건강           중성화 O · 접종 O · (특수요구)
─ 소개글 / 구조 사연
─ 임보 조건 (임보 글일 때만)   기간:장기 / 비용 안내
─ ⓘ "keeper는 거래 당사자가 아닙니다" 면책 고지     ← P0
─ ⚠️ "만나기 전 송금 금지 · 공공장소 안내" 배너      ← P0
─ [ 💬 문의하기 ]   ♡ 저장      ← 연락처 게이팅 (P0)
─ ⋯ 신고하기                    ← P0
```

**UI 3원칙**: ① 연락처 본문 노출 X — `[문의하기]` 눌러야(로그인) 게이팅 노출 ② 신고 버튼 상시 노출 ③ 안전·면책 고지를 문의 버튼 위에.

## 4. 출시 후 개선 (P1) — GitHub 이슈

- **1:1 채팅 문의** — 외부 연락수단 게이팅을 앱 내 대화방(`conversation`+`messages`)으로. **프로토타입 기존 보유 → 저비용. 첫 이슈 후보.** 입양 외 실종·QnA 재사용.
- **입양자-동물 매칭 / 매칭 퀴즈 연동**(`breed-matchmaker`·`adoption-quiz`) — 공고 수 쌓인 뒤 의미. 후순위.
- **단계형 위저드 + 진행 상태머신**(신청검토→만남→확정) — "문의 컨택" 모델엔 과함. 후순위.
- **고양이 성격유형 분류**(Feline-ality 9종 등) — 게시폼 표준 채택 사례 미확인(조사). 공통 성격 태그로 충분, 9종 분류는 신중 검토.

> 영상·성격 태그·구조 사연·임보 조건은 **P0(출시 폼)로 이동** — 조사상 표준 정합이고 비민감이라 부담 작음.

## 5. 미해결 / 착수 시 확인

- Petfinder Pro / Adopt-a-Pet Rehome 실제 게시 폼이 단일 폼인지 멀티스텝인지·정확한 필수 개수는 **검증 기각/미확정** (계정으로 직접 캡처 필요).
- 국내 게시 폼(포인핸드 입양홍보·동물자유연대·카라) 필드 목록 **1차 실측 미확정** — 이번엔 KARA browse 필터·핌피 listing 노출만 확인.
- 게시 폼(동기 높은 게시자)의 필드 수↔완료율 정량 데이터는 약함(e커머스 체크아웃 기준만 생존) → 외삽 주의.
- 완전 무상 시 통신판매중개자 100% 면제 여부 판례 없음 → 보수적 고지·무상 한정.
- 임보를 "거래" 아닌 "위탁/돌봄"으로 볼 때 법적 성격 회색지대 → 비용은 안내 텍스트로.
