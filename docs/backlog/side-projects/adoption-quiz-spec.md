### ⑤ 입양 완료 자동 감지

Keeper에서 그 강아지 `processState` 변경 (입양 → 종료) 감지 → 자동 알림:

```
📩 [Keeper] 토리 입양 축하해요!
```

### ⑥ Follow-up — 30/60/90일

```
📩 [Keeper] 토리 잘 지내고 있나요?

   3가지만 체크 (1분):
   · 분리불안:  ○ 좋음 ○ 보통 ○ 어려움
   · 배변:      ○ 좋음 ○ 보통 ○ 어려움
   · 만족도:    ★★★★★
```

데이터 누적 → 알고리즘 개선 + 파양율 측정 (mission KPI).

## 4. Quiz 12문항 (확정)

거주·환경 3 / 가족·생활 3 / 라이프스타일 3 / 경험·capacity 3

```
Q1. 어디서 살아요?
Q2. 산책 환경은? (공원 거리)
Q3. 평일 집에 있는 시간?
Q4. 산책 가능한 시간?
Q5. 가족 구성? (1인·부부·아이·노부모·다른 반려동물)
Q6. 반려동물 경험?
Q7. 강아지와 어떻게 시간 보내고 싶어요? (활발·균형·정적)
Q8. 훈련에 들일 시간·의지?
Q9. 행동 문제 다룰 자신? (짖음·낯가림·물림)
Q10. 강아지 크기 선호?
Q11. 나이 선호? (어린·청년·중년·노령·무관)
Q12. 월 양육 예산?
```

→ 각 답이 5축 점수 (친화성·신경성·개방성·외향성·우위성 = Big Five) + hard filter (크기·나이·아이 fit 등)에 영향.

## 5. 매칭 알고리즘 (간단 설명)

```
1. Hard filter (불가 매칭 제거)
   · 사용자가 소형 선호인데 강아지 대형 → 제외
   · 사용자 아이 있는데 강아지 어린이 X → 제외
   · 사용자 예산 < 강아지 의료비 → 제외

2. 5축 거리 계산 (Euclidean distance)
   · 사용자 Big Five score (Quiz로 산출)
   · 강아지 Big Five score (견종·나이·특이사항 text mining)
   · 거리 가까울수록 매칭 ↑

3. 가중치 합산
   매칭 = 5축 일치 × 0.35
        + 활동량 매치 × 0.25
        + 환경 fit × 0.20  (대형견 + 원룸 = 30점)
        + 거리 fit × 0.20  (같은 시군구 = 100점)

4. Top 5 추출 (보호소 다양성 가중)
```

→ 강아지 5축 점수는 견종 default + 나이·체중 조정 + specialMark text mining 자동 추출.

## 9. Roadmap

### Phase 1 — MVP (1~2주)

- Quiz 5문항부터 시작 (Q1·Q4·Q6·Q10·Q11)
- Hard filter + 단순 weighted score
- 결과 5마리 카드 (Keeper 기존 공고로 link)
- 본인 + 친구 5명 테스트

### Phase 2 — 확장 (3~4주)

- Quiz 12문항·5축 OCEAN scoring
- GPT-4o 매칭 이유 자연어 생성
- 견종 default profile 30개 (FCI 기반)
- Keeper user 30명 시드 테스트

### Phase 3 — Follow-up (1~3개월)

- 입양 완료 자동 감지 (processState 변경)
- 30/60/90일 cron + 푸시·이메일
- 파양율 측정 layer

### Phase 4 — 데이터 누적 + 효과 입증 (6개월~)

- 매칭 quiz 입양 vs 일반 입양 파양율 비교
- 데이터 누적 → 알고리즘 ML 개선
- 효과 데이터로 언론·정책 leverage
