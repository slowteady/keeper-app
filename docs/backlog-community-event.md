# 백로그: 커뮤니티 + 이벤트·지원사업 큐레이션

작성일: 2026-04-20
상태: 아이디어 확정, 스펙 상세화 대기

---

## 배경 / 왜

- 현재 Keeper는 유기동물 입양 공고 앱 → 체류 시간 짧고 방문 일회성
- 재방문 동기 강화 필요
- 반려인이 실질적으로 필요로 하는 정보(지원사업, 박람회, 입양회, 봉사)가 **네이버 카페/맘카페에 파편화**되어 있고, 전문 큐레이션 앱이 없음
- Keeper 타겟층과 100% 일치 → 부가 기능이 아니라 2차 핵심 축으로 삼을 수 있음

## 전략 축

1. **커뮤니티** (아직 미배포) 런칭에 이벤트/지원사업 피드를 같이 얹는다
2. **이벤트/지원사업 피드**가 커뮤니티 초기 시드 콘텐츠 역할 → "빈 커뮤니티" 문제 해결
3. **유저 제보 + 편집자 검증**으로 크롤링 빈틈을 보완

---

## 선행 조건

### 지역 설정 (필수 선행)

- 당근마켓 레퍼런스
  - GPS 기반 현위치 동네 인증
  - 수동 검색으로 동네 추가
  - 최대 2개 동네 등록 (현재/본가 등)
  - 주기적 인증 갱신 (이사 감지)
- Keeper 특성: 반려인은 이사 잦지 않음 → 2개면 충분
- 추가 고려: "임시 방문 지역" 필터 (본가 방문 시 주변 박람회 조회)
- **이벤트·커뮤니티 모두의 전제**이므로 가장 먼저 개발

### 유저 프로필 확장

- 반려동물 정보 (종, 크기, 나이) → 지원사업 매칭 정확도 개선
- 관심 카테고리 (지원사업/박람회/봉사 등) 선택 → 알림 필터링

## 이벤트 타입 (5종)

유형별로 성격이 다르므로 수집 전략을 분리한다. 데이터 모델은 하나로 통합하되 `type` 필드로 구분.

| 유형        | 데이터 소스                   | 수집 방식           | 실시간성       |
| ----------- | ----------------------------- | ------------------- | -------------- |
| 지원사업    | 지자체 공지/공식 블로그       | 크롤링 (→ 웰로)     | 중 (마감 민감) |
| 박람회      | 케이펫페어/메가주/펫서울 공식 | 수동 or 공식 크롤링 | 저 (연례 정형) |
| 입양회      | 지자체 + 카라/동물자유연대    | 크롤링 + 유저 제보  | 중             |
| 펫카페 행사 | 인스타 태그 산재              | **유저 제보만**     | 고 (주말 단위) |
| 봉사        | 보호소 홈 + 1365자원봉사      | 크롤링 + 유저 제보  | 중             |

---

## 데이터 모델 (초안)

```ts
Event {
  id
  type: '지원사업' | '박람회' | '입양회' | '카페행사' | '봉사'
  title
  region: { sido, sigungu, dong? }  // 지역 매칭용
  period: { start, end }
  deadline?                         // 지원사업: 신청 마감
  budgetExhausted?: boolean         // 지원사업: 예산 소진 플래그
  source: {
    type: 'crawl' | 'user' | 'editor',
    url?,
    reporterId?
  }
  verifiedBy?: editorId             // 유저 제보 → 편집자 승인 시 세팅
  thumbnailUrl?
  createdAt
  updatedAt
}
```

- 지역 매칭: `sigungu` 단위 기본. 광역 이벤트(박람회)는 `sido`만.
- 알림 트리거: 새 이벤트 등록, 마감 임박(지원사업), 예산 소진 플래그 변경

## 로드맵

### Phase 0: 선행 작업

- 지역 설정 기능 (당근 레퍼런스)
- 유저 프로필 확장 (반려동물 정보, 관심 카테고리)

### Phase 1: 커뮤니티 런칭 + 이벤트 피드 (수동)

- 커뮤니티 기본 기능 정비 (미배포 상태 점검)
- 이벤트 피드 섹션 추가
- 시드 콘텐츠 30개 운영자 수작업 (지원사업 10 / 박람회 5 / 입양회 5 / 봉사 10)
- 동물권 단체(카라, 동물자유연대, 지역 보호소) 사전 연락하여 이벤트 등록 협조 요청

### Phase 2: 유저 제보 시스템

- "이벤트 제보" 버튼 → 커뮤니티 게시 → 편집자 승인 → 공식 피드 승격
- 제보자 보상 (배지/포인트)
- 편집자 대시보드 (승인/반려/수정)
- **펫카페 행사·지역 소규모 입양회는 이 경로로만 커버**

### Phase 3: 자동 크롤러

- 서울시 공식 블로그
- 경기도 분야별 정보
- 부산시 반려동물 페이지
- (선택) 카라·동물자유연대 공지
- → 이 3-5개로 **반려인 50%+ 커버** (서울·경기 반려동물 등록 비중)

### Phase 4: 커버리지 한계 확인 후 웰로 B2B API 검토

- welloapi.com 라이선스 비용 문의
- 자체 크롤러 확장 vs 웰로 연동 비교
