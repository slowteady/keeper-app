## 이전 기록

이슈 기반으로 바꾸기 전(2026-10-28 이전)의 문서다. 고치지 않고 참고만 한다.

| 위치                 | 내용                      | 언제 읽나                                     |
| -------------------- | ------------------------- | --------------------------------------------- |
| `spec/`              | 기능별 기술 명세 (번호순) | 기존 기능의 데이터·API 결정을 확인할 때       |
| `prd/` · `design/`   | 기능별 요구사항·화면 설계 | 기존 기능의 범위·화면 의도를 확인할 때        |
| `qa/` · `review/`    | 기능별 검수 결과          | 기존 기능의 알려진 한계·미결 항목을 확인할 때 |
| `backlog/`           | 기능 후보·로드맵          | 다음에 할 일을 고를 때                        |
| `archive/`           | 완료된 기능의 초기 문서   | 오래된 기능의 배경을 찾을 때                  |
| `superpowers/specs/` | 알림·분석 설계 초안       | 알림·분석 기능의 배경을 찾을 때               |
